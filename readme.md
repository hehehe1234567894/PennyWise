# 💰 PennyWise · 智能记账机器人

> **一句话说明**：把支付截图发给机器人，账就自动记好了。

---

## 📌 项目概述

PennyWise 是一个运行在 **QQ** 上的个人财务管理助手。它利用 AI 技术，让你彻底告别手动输入账单的繁琐。

你只需将 **微信 / 支付宝 / 银行 App** 的支付截图（或转账记录截图）通过 QQ 发送给机器人，它就能自动识别出**消费金额**、**商户名称**和**消费类别**，并实时更新你的月度预算，让你随时掌握财务状况。

---

## ✨ 核心功能

### 1. 截图即记账
- 支持单聊发送图片，或群聊中 `@机器人` 并附上截图。
- 自动下载图片并提取关键信息，无需任何手动输入。

### 2. 智能识别与归类
- 自动识别金额、商户名称、消费时间。
- 根据商户名智能归类到**餐饮、交通、购物、娱乐、生活缴费、转账、其他**等类别。
- 可自定义分类规则，适应个人习惯。

### 3. 实时预算提醒
- 每月为每个类别设定预算上限。
- 记账后即时反馈该类别本月已用金额及剩余额度。
- 当消费接近或超出预算时，主动发出预警，避免冲动消费。

### 4. 人工确认机制（防错纠错）
- 当 AI 对识别结果不够自信时，会主动发送确认消息。
- 用户只需回复“是”或“否”，即可修正数据，确保每笔账目准确无误。

### 5. 月度消费报表（规划中）
- 每月自动生成统计图表，直观展示各类别消费占比。
- 支持通过命令（如 `/报表`）随时查看本月支出汇总。

### 6. 越用越聪明
- 机器人会记住你对商户的手动分类，下次遇到同一商户，秒级匹配，无需重复调用 AI，响应更快。

## 🎯 使用场景

| 场景 | 说明 |
| :--- | :--- |
| **日常消费记账** | 买咖啡、午餐、打车后，随手截图发给机器人，记录每一笔开销。 |
| **月度预算控制** | 设定餐饮预算 2000 元，每当消费一笔，立即看到剩余金额，防止超支。 |
| **多人合租 AA 记账**（规划中） | 在群聊中发送“AA 午餐 120 元”，机器人可自动计算每人应付金额并记录。 |
| **财务回顾** | 月底查看报表，了解钱都花在哪里，优化下月开支计划。 |

## 💡 特色亮点

- **零门槛操作**：会发截图就能用，不需要打开任何 App 或手动输入数字。
- **全自动流程**：从识别到记录，全程无需人工干预（除非需要确认）。
- **实时反馈**：记账后立即得到回复，包含金额、类别和预算剩余，一目了然。
- **隐私安全**：所有数据仅存储在用户本地或自己可控的服务器，不经过第三方。
- **低成本运行**：利用免费 OCR 和 AI 模型，个人使用几乎零成本。

## 🔮 未来升级方向

- 支持**语音记账**：直接发送语音消息“午餐消费 35 元”，自动转文字并记账。
- 支持**账单导入**：支持支付宝/微信账单 CSV 批量导入，一次性分析整月数据。
- **多人共享账本**：家庭或情侣可共同使用一个账本，同步消费记录。
- **智能省钱建议**：基于历史消费数据，提供个性化省钱建议（如“本月餐饮支出已超上月，建议减少外卖”）。

## 📱 如何开始使用？

1. 添加机器人为 QQ 好友（或邀请入群）。
2. 发送任意支付截图。
3. 收到记账确认回复后，即完成一次记账。
4. 每月可发送 `/报表` 查看汇总统计。
