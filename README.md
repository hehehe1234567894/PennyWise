# PennyWise 💰

**零手动记账**：粘贴交易通知或直接发支付截图 → AI 解析 → 一键确认入账。数据全部存在你自己电脑的 SQLite 里，不买服务器；手机扫码即连，在家走内网、在校走 Tailscale，全程自动。

> 架构与设计决策（校园网、蓝牙评估、检测机制）见 [docs/architecture.md](docs/architecture.md)

## 三步上手（这台电脑已配置好）

1. **电脑**：开机自动在后台运行，无需任何操作。也可以双击桌面的「PennyWise 记账」图标手动打开页面（http://localhost:8720）。
2. **AI 模型**：DeepSeek Key 已配置。以后要换 Key：打开页面 → 右上角 ⚙ → 设置里粘贴保存（不用碰配置文件）。
3. **手机配对**：电脑上打开页面 → ⚙ 设置 →「连接手机」处用 **iPhone 相机扫码**：
   - 在家：扫「局域网」码，无需装任何 App；
   - 校园网/出门：扫「Tailscale」码（手机装 Tailscale 登录同一账号）。
   - 扫码后自动完成配对（令牌免输入），再点分享 → **添加到主屏幕**，之后就像用 App 一样。

之后手机上：打开 PennyWise → 粘贴交易文本 / 选截图 → 解析 → 看一眼金额商户 → 确认。顶栏会显示当前通道（局域网直连 / Tailscale），网络不通时交易自动存手机、恢复后补传。

## 双向同步（电脑不开机也能记账）

手机和电脑各自保存一份**完整本地账本**，任何操作（记一笔、确认、修改、删除）都**先在本机立即生效**，网络连通时自动合并，冲突按"最后修改者胜"：

- **手机离线**：照常记账、确认、修改、看流水和统计；连上电脑后自动同步（顶栏显示"待同步 N"）
- **电脑离线/关机**：手机完全不受影响——这就是为什么你现在不需要"每次记账都开电脑"
- **电脑端记的账**：手机下次同步自动收到
- 离线拍的截图：先存在手机上，同步时上传并自动跑视觉识别
- 每条账目有全局唯一 ID + 修改时间戳，同步幂等、重试不重复

> 电脑的角色从"必须开机的服务器"降级为"同步中枢 + AI 解析器"：它开机时帮你做 AI 识别和两家设备的合并；它关机时手机独立工作。

## 日常使用（怎么记账）

- **📸 分享式记账（最快）**：支付后截图 → 系统分享面板 → 点 **PennyWise** → 自动识别。**不需要快捷指令**。前提：手机通过 HTTPS 域名打开并已添加到主屏幕（见下方说明）；识别置信度 ≥ 90% 会自动直接入账，连确认都省了。
- **📱 银行短信自动记账（0 点击）**：设置页下载「快捷指令」→ 导入 → 在「快捷指令 App → 自动化 → 收到信息」里选择发卡银行号码并运行它。之后生活费/奖学金到账、刷卡消费的短信一到，自动入账；验证码等无关短信自动忽略。
- **📊 账单邮件自动导入（主方案，0 点击）**：每 12 小时自动检查邮箱，**只读取白名单发件人**（微信/支付宝/银行）的账单邮件并解析入库，其他邮件一律不碰、不上传云端。支持微信账单（链接下载加密 zip → xlsx）、支付宝账单（加密 zip 附件 → 电子回单 CSV）、银行对账单 CSV（GBK），按交易单号自动去重；失败/失败的还款行自动过滤。
  - **多策略解析链**：确定性列识别（各平台多格式）→ 失败 → **LLM 列映射兜底**（列下标识别后确定性解析）。
  - **加密 zip 与密码邮件自动配对**：主题「微信密码」/「支付宝密码」分平台配对，密码规则提取失败自动 LLM 提取；zip 与密码邮件先后顺序无关。
  - **LLM 合并审核（账单是最终权威）**：账单行与已有手记/截图记录做疑似重复检测（时间 ±40h、金额 ±0.05、同方向），候选对**一次性批量交给 LLM 判定合并**——匹配则给已有记录挂上账单单号（不重复插入），不匹配则作为新交易入库。零候选 = 零 token。
  - **LLM 批量分类**：无规则记忆的支出商户去重后**一次调用**统一分类（商品名辅助判断，商户被脱敏时以商品名为准），结果写入规则记忆——同一商户下月起 0 token、实时记账也自动复用。`BILL_LLM_MERGE=0` / `BILL_LLM_CATEGORIZE=0` 可分别关闭。
  - **银行对账单是真正的全自动来源**：网银开启"每月电子对账单发送到邮箱"后永久自动，且覆盖所有银行卡交易（含微信/支付宝用卡支付）。

> **解压密码邮件格式（你的规则）**：发件人 = 你自己（`MAIL_USER`），标题 =「微信密码」或「支付宝密码」，正文只放密码本身（4–16 位字母数字）。也兼容「密码：XXXX」等格式；规则提取失败时自动用 LLM 兜底。系统只对你本人和白名单发件人的邮件做密码提取，你的邮件**绝不读取附件**。
- **粘贴记账**：复制交易通知 → 打开 PennyWise → 点「粘贴」→ 自动解析（一键完成）。
- **选图记账**：App 里点「选截图」，或电脑上直接 Ctrl+V 粘贴截图 / 拖拽图片。
- **自动入账阈值**：设置里可调（0.9 推荐 / 1.0 = 全部手动确认）。低置信度的交易进「待处理」，你只处理 AI 没把握的那几条。
- **电脑端**：微信/支付宝 PC 客户端复制通知直接粘进来。
- **数据**：存在 `data/pennywise.db`（截图在 `data/images/`），备份 = 复制 `data` 文件夹。
- **停止/重启服务**：
  - 停止：`powershell -ExecutionPolicy Bypass -File scripts\stop.ps1`
  - 启动：双击桌面图标，或运行 `scripts\open.vbs`
  - 取消开机自启：删除「启动」文件夹里的 `PennyWise.vbs`（Win+R 输入 `shell:startup` 打开）

> **分享式记账为什么需要 HTTPS**：iOS 只允许"已添加到主屏幕的 HTTPS 网页"出现在分享面板里。在电脑上执行 `tailscale serve --bg 8720`（首次按提示在 tailscale.com 开启 HTTPS 证书），然后手机用 `https://mkk-98.tailb46f33.ts.net` 打开并添加到主屏幕即可。局域网地址的二维码仍可扫码记账，只是没有分享面板入口。

> **邮件配置（163 邮箱）**：网页版 → 设置 → POP3/SMTP/IMAP → 开启「IMAP/SMTP 服务」→ 设置「客户端授权密码」（**授权码不是登录密码**）。然后 `.env` 填：`AUTO_IMPORT=1`、`MAIL_CAPTURE=1`、`MAIL_IMAP_HOST=imap.163.com`、`MAIL_USER=你的163邮箱`、`MAIL_PASS=授权码`，发送通道同样填 `SMTP_HOST=smtp.163.com`、`SMTP_PORT=465`、`SMTP_USER/PASS=同上`、`MAIL_TO=你的邮箱`。QQ 邮箱同理（`imap.qq.com` / `smtp.qq.com`）。
> 支付宝：我的 → 账单 → 邮件账单（可设每月自动发送）；微信：钱包 → 账单 → 下载账单 → 发送到邮箱（每月一次）。注意账单邮件可能被投进垃圾箱，若自动导入不到，把 `.env` 的 `MAIL_BOX` 改成垃圾邮件文件夹名。

## 安全

- **锁定屏**：**没有通过验证就进不了网页**——电脑本机与手机一视同仁。首次打开在锁定屏粘贴 `.env` 里的 `AUTH_TOKEN`（令牌）验证，通过后浏览器记住令牌、之后自动进入；令牌失效（如你在 `.env` 里换过）会立即重新锁定。手机端同样验证一次后自动进入，也可用电脑「设置」里的二维码配对。
- **数据接口**：除二维码渲染外，所有 `/api` 读写接口必须携带 `X-Auth-Token`，无令牌或令牌错误一律 401（令牌比对用恒定时间算法，防时序侧信道），不再有"本机免令牌"通道；`/shortcut` 快捷指令下载必须带令牌参数。
- **防恶意网页（CSRF / DNS rebinding）**：浏览器跨站请求（`Sec-Fetch-Site: cross-site`）一律 403；带 `Origin` 的请求只放行服务器自己的地址（本机 IP、局域网 IP、Tailscale 域名），陌生来源 403 且不回显 CORS 头，响应不可被读取；CORS 白名单外的预检 OPTIONS 直接 403。即使令牌泄露进浏览器缓存，别人网站上的页面也无法读写你的账本。
- **限流**：每 IP 每分钟最多 120 次 API 请求，超限返回 429，防暴力猜令牌。
- **截图文件**：存储名是 16 位随机十六进制，不可枚举，且文件读取路径做了防目录穿越校验；页面带 CSP / nosniff / 防嵌入等安全响应头。
- **手机快捷指令**：生成快捷指令链接时需要令牌（`/shortcut?t=…`），远程机器拿不到；上传接口同样验证令牌。
- **传输**：Tailscale 端到端加密；财务数据只落本地 SQLite，上云部分仅限你发给模型的单条交易文本/截图。

## 月报提醒

每月 1 日 9 点自动把上月汇总发送给你。**月报由 LLM 撰写分析**，并带**纯 CSS 图表**（邮件客户端不支持 JS，图表用 div 绘制，163 网页版与 iPhone 邮件均可正常显示）：

- **📊 支出分类条形图**：各类目金额占比一眼看清；
- **📈 近 6 个月支出趋势柱状图**：当月高亮，消费走向直观；
- **📝 AI 分析**：基于真实数据的洞察（亮点、异常、环比、预算建议）；

- **🛒 省钱与升级建议（根据你的账单）**：AI 分析你的月度账单，挑选 1-3 个在用的商品/服务（订阅/会员、高频重复购买、大额消费），联网搜索后给出**两个方向**：
  - 💰 **更便宜的方案**：只推比你现价低的（标注每个方案价格和比现价省多少）；
  - ⬆️ **更好的升级产品**：比你现在用的体验/效果更好的产品（可以更贵，说清好在哪、值不值得换）。
- **连续两月不重复**：系统记住上月推荐过的商品，本月自动排除，避免每次都推同样的东西。

三种接收方式任选（可叠加）：

1. **邮件（推荐，零额外服务）**：`.env` 填 `SMTP_HOST=smtp.qq.com`、`SMTP_PORT=465`、`SMTP_USER=你的QQ邮箱`、`SMTP_PASS=授权码`。iPhone 邮箱 App 原生推送；把 QQ 邮箱绑定微信「QQ邮箱提醒」，月报就直接推到你微信里（QQ App 的邮箱提醒同理）。
2. **微信直推（可选）**：到 [sct.ftqq.com](https://sct.ftqq.com) 微信扫码登录拿 SendKey，填 `SERVERCHAN_KEY`，月报以微信服务号消息送达。
3. 测试：设置页 →「月报提醒」→ 发送本月测试月报。

> 163 邮箱授权码：网页版 → 设置 → POP3/SMTP/IMAP → 开启服务 → 设置「客户端授权密码」（与账单导入/邮箱记账的 `MAIL_PASS` 可共用同一个）。QQ 邮箱同理（设置 → 账户 → 开启 IMAP/SMTP → 生成授权码）。

## 邮箱沟通 AI Agent

AI 助手有两个入口，同一套大脑（记账 / 查账 / 平替推荐 / 闲聊）：

- **网页版**：打开 PennyWise 网页，点右下角 **🤖 AI 助手** 悬浮按钮，直接对话框交流（记账后流水/统计自动刷新）。
- **邮箱版**：开启 `MAIL_CAPTURE=1` 后，**给自己邮箱发一封主题为 PW 的邮件**即可与你的账本对话（每 3 分钟自动处理并回信，只读主题为 PW 的邮件，其他邮件一律不碰）：

| 你想做什么 | 内容示例 | 回复 |
|---|---|---|
| 记账 | 正文写交易文本，或附支付截图 | 「已自动记账 ✓ 全家便利店 ¥18.50」 |
| 查账 | 「这个月我花了多少？主要花在哪？」 | 真实数据回答（总额/分类/环比） |
| 平替推荐 | 「想买蓝牙耳机，预算200以内，有平替吗」 | **联网搜索真实价格** + 2-3 个替代方案 + 结合你的结余给建议 |
| 闲聊/功能询问 | 任意问题 | AI 回答 |

全部由 LLM 驱动（DeepSeek 做意图路由与回复，阿里云 qwen 联网搜索做比价）。

## 模型故障提示

界面平时**不显示任何模型相关内容**；只有当模型无法调用时（欠费 / Key 无效 / 限流 / 服务异常 / 未配置），页面顶部会出现黄色提示条，说明哪一路出了问题（文字解析 / 截图识别）和修复方式，点提示条直达修复页。模型恢复正常后提示自动消失。识别失败时交易自动转手动确认，**记账流程不会被欠费打断**。

## 换一台电脑时重新部署

1. 装 [Node.js](https://nodejs.org/)（≥ 22.5），把本目录拷过去；
2. `npm install` → `npm start`；
3. 首次运行会自动生成 `.env`（随机令牌）；DeepSeek Key 直接在网页设置里粘贴；
4. 可选：手机装 Tailscale 登录同一账号，电脑执行 `tailscale serve --bg 8720`（首次需按提示在 tailscale.com 开启 HTTPS 证书），并在 `.env` 填 `TAILSCALE_NAME=电脑名.tailnet.ts.net`。

## 换模型 / 成本

文本模型接口均为 OpenAI 兼容格式，网页设置或 `.env` 三行即可切换：

- 智谱：`LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4`，`LLM_MODEL=glm-4-flash`
- 阿里：`LLM_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1`，`LLM_MODEL=qwen-plus`
- 本地 Ollama（完全离线）：`LLM_BASE_URL=http://127.0.0.1:11434/v1`，`LLM_MODEL=qwen2.5:7b`

**视觉模型降级链**：`.env` 里的 `VISION_MODELS` 按顺序尝试，前面的失败（网络/报错/格式问题）自动换下一个，默认：

```
qwen3-vl-flash → qwen3.7-flash → qwen3.5-flash → qwen-vl-plus
```

DeepSeek 解析一条交易约 ¥0.001，截图一张约 ¥0.01–0.05，几百笔/月成本几毛到几块钱。
